Closure in JavaScript

Problem: Why does the following code print the number 6 five times after a second, instead of 1 to 5?
function test(){ for(var i=1;i<=5;i++){ setTimeout(()=>{ console.log(i) },1000) } } test();
Explanation:
Because var is function-scoped, all timeouts share the same i variable, which ends up as 6 after the loop finishes.
How to fix it without changing var to let?
  1. Passing i as an argument to setTimeout:
    function test1(){ for(var i=1;i<=5;i++){ setTimeout((x)=>{ console.log(x) },1000,i) } } test1();
  2. Using IIFE (Immediately Invoked Function Expression):
    function test2(){ for(var i=1;i<=5;i++){ (function(i){ setTimeout(function(){ console.log(i) },1000); })(i); } } test2();
  3. Change var to let:
    for (let i = 1; i <= 5; i++) { setTimeout(() => console.log(i), 1000); }
Why does let work?
  • let is block-scoped.
  • Each iteration gets its own i.
