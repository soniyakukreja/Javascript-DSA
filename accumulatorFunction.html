Accumulator Function

An accumulator function is a function that maintains a running total or result as it processes a sequence of values. It is commonly used in array methods like reduce in JavaScript.

Simple Example

// Accumulator function to sum numbers in an array
function sumArray(arr) {
    return arr.reduce(function(acc, curr) {
        return acc + curr;
    }, 0);
}

const numbers = [1, 2, 3, 4, 5];
console.log(sumArray(numbers)); // Output: 15

Explanation:
- acc is the accumulator that keeps the running total.
- curr is the current value in the array.
- The function adds each value to the accumulator, starting from 0.
- The final result is the sum of all numbers in the array.

When to use?

  • When you need to combine all elements of an array into a single value (sum, product, etc.).
  • When you want to process a sequence and keep a running result.
