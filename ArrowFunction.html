Arrow Function

Limitations
  • 1. no own this (this displays value from lexical environment)
  • 2. not constructor
  • 3. no own arguments object
  • 4. no prototype
  • 5. no yeild and generator function
  • 6. Not Ideal for Event Handlers (sometimes if you need this in the function)
  • 7. Cannot Be Hoisted Like Function Declarations
  • When Should You Use Arrow Functions?
  • ✅ Short callback functions
  • ✅ Array methods (map, filter, reduce)
  • ✅ When you want lexical this (React, closures)
