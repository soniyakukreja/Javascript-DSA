Reduce Function in JavaScript

The reduce function is a powerful array method in JavaScript that processes each element of an array and reduces it to a single value. It takes a callback function (the reducer) and an optional initial value.

Simple Example

// Using reduce to sum numbers in an array
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce(function(acc, curr) {
    return acc + curr;
}, 0);
console.log(sum); // Output: 15

Explanation:
- acc is the accumulator (the running total).
- curr is the current value in the array.
- The function adds each value to the accumulator, starting from 0.
- The final result is the sum of all numbers in the array.

Other Use Cases for reduce()

  • Finding the maximum or minimum value: 
    const max = numbers.reduce((acc, curr) => acc > curr ? acc : curr, numbers[0]);
  • Flattening an array: 
    const nested = [[1,2], [3,4], [5]];
const flat = nested.reduce((acc, curr) => acc.concat(curr), []);
  • Counting occurrences: 
    const fruits = ['apple', 'banana', 'apple'];
const count = fruits.reduce((acc, curr) => {
    acc[curr] = (acc[curr] || 0) + 1;
    return acc;
}, {});

When to use reduce?

  • When you want to combine all elements of an array into a single value (sum, product, etc.).
  • When you need to transform an array into an object or another array.
  • When you want to process a sequence and keep a running result.
  • When you want to perform complex calculations or aggregations on array data.
